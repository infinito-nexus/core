# Documentation Lint 📄

Markdown-link resolvability and CLI-category README presence.

Tests in this directory MUST only cover documentation artefacts (`*.md`, README presence). Code-level rules MUST live under [`python/`](../../filesystem/python/), [`shell/`](../../filesystem/shell/), or [`yaml/`](../yaml/).

For framework and `make test-lint` usage see [lint.md](../../../../docs/contributing/actions/testing/lint.md).
