- Drop the custom image build once the pinned Mobilizon release ships erts 17.1 (OTP 29.1) or newer. Older erts hands `sigaltstack` a fixed 8192-byte stack, and musl 1.2.6 (Alpine 3.24) rejects any stack below `AT_MINSIGSTKSZ` plus 1024, so on hosts with a large signal frame (AMX) the BEAM aborts at start with `Failed to set alternate signal stack`. `files/Dockerfile` therefore preloads a shim that calls the raw `sigaltstack` syscall, which the kernel accepts for a task without AMX permission.
